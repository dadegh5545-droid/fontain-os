# docs/

مواصفات المنتج والقرارات المعتمدة. تُقرأ بهذا الترتيب:

1. [`DECISIONS.md`](./DECISIONS.md) — سجل القرارات (`D-xx`). أي تغيير فيه يستلزم `DECISION REQUIRED`.
2. [`blueprint.md`](./blueprint.md) — Product Blueprint: System Map، Role Map، Screen Map، Automation Map، حدود V1، ترتيب الـSprints.
3. [`data-schema.md`](./data-schema.md) — الكيانات، Enums، Routes، Custom Mutations.
4. [`implementation-plan.md`](./implementation-plan.md) — تقسيم الفريق، هيكل المستودع، البيئات، الأسرار، الاختبار، Git Workflow، Definition of Done، Rollback، قاعدة DECISION REQUIRED.
5. [`sprints/sprint-0.md`](./sprints/sprint-0.md) — Sprint 0 Foundation (المهام `FOS-000` … `FOS-011`).
6. [`sprints/sprint-1.md`](./sprints/sprint-1.md) — Sprint 1 Leads + Interactions.

الملفات أعلاه منسوخة حرفيًا من المواصفة المعتمدة ومستثناة من `prettier` عمدًا. تعديلها يمر عبر PR بمراجع واحد (انظر `CODEOWNERS`).
